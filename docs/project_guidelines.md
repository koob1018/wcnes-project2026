# WCNES Backscatter 项目总准则

## 1. 文档目的
本文件用于统一本项目的开发边界、实验目标、验证流程与协作规范。

核心目标：
- 降低 PER（最高优先级）
- 降低 BER（第二优先级）
- RSSI 仅作为辅助指标

本项目是代码实现 + 实验验证 + 日志分析的联合工程，不是纯软件项目。

## 2. 实际硬件分工（以当前实验平台为准）
- Carrier：nRF52840 板
  - 作用：发 unmodulated carrier
  - 当前策略：carrier 端默认不改代码
- Tag：Pico 板（双天线）
  - 作用：产生 backscatter 2-FSK 信号
  - 主要优化对象：频偏、偏移、符号率、帧结构与可靠性相关参数
- Receiver：CC1352 板
  - 作用：接收并通过上位机软件采集日志
  - 当前策略：主要通过配置匹配 tag 参数，不重写协议栈

## 5. 参数优化原则（先小改，后扩展）
每轮实验只改一个主变量，其余保持不变。

建议优先级：
1. 2-FSK 相关基础参数（如频偏/中心偏移/符号率）
2. 发包节奏与负载相关参数
3. 帧结构相关参数（syncword/preamble/header）

不建议一开始就改：
- syncword 与 preamble 的大幅调整
- 多变量同时扫描
- 协议字段重排

## 10.1 分频参数、波特率、中心偏移与频偏的关系（关键口径）
以主工程实现为准，Tag 侧核心输入参数是 d0、d1、baud（见主工程与 backscatter 库调用链）。

参数含义：
- d0、d1：两个符号对应的时钟分频值（分别映射 2-FSK 的两个频点）
- baud：符号率（每秒符号数）

由 d0、d1 推导得到：
- f0 = CLK / d0
- f1 = CLK / d1
- center_offset = (f0 + f1) / 2
- deviation = |f1 - center_offset| = |f1 - f0| / 2
- minRxBw ≈ baud + 2 × deviation

工程结论：
- 改分频参数（d0/d1）本质是改两个符号频点，因此会直接改变 center_offset 与 deviation。
- 改波特率（baud）主要改变符号时长和占用带宽中的符号率项；它不会直接设定两个频点位置，但会影响可实现时序与接收带宽要求。
- 在本项目链路中，receiver 端应匹配 Tag 推导出的 center_offset、deviation、baud、filter bandwidth。

调参优先建议（单变量）：
1. 先固定 baud，优先调 d0/d1，把 deviation 与 center_offset 调到可收、稳定区间
2. 再小步调 baud，观察 PER/BER 与带宽裕量变化
3. 每次只改一个主变量，保持场景 S0 不变

说明：
- 你提出的“主要改 deviation 和 tag 的 offset”是对的，但这两个量在当前实现里主要由 d0/d1 间接决定，而不是独立自由参数。
- 如果需要细调 offset 而尽量不改 deviation，应让 d0/d1 同向小步变化并保持两者间距近似不变。

## 10.2 频谱分析仪一屏观测模板（每次都看这三项）
目标：不做复杂 RF 调试，只获取能支撑实验结论的最小证据。

现场执行请优先参考：`docs/spectrum_measurement_playbook.md`。

建议固定显示：
- Trace 类型：Max Hold（用于看峰值位置）
- Marker：M1、M2（锁定两条 backscatter 边带）
- 带宽测量：OBW（99% 占用带宽）

单屏需要记录的三项：
1. 两个峰值频率（M1=f0，M2=f1）
2. 99% OBW
3. 边带相对载波功率（任选一个边带，记 dBc）

一屏解读：
- center_offset = (f0 + f1) / 2
- deviation = |f1 - f0| / 2
- 验证带宽关系：OBW 与 (baud + 2*deviation) 同量级且趋势一致

最小操作步骤（通用，不依赖具体机型菜单名）：
1. 设定 Center = 2450 MHz，Span = 20 MHz（先看全局）
2. Ref Level 调到不压顶，RBW 先用 30 kHz，VBW >= RBW
3. 打开 Max Hold，观察 5-10 秒使轨迹稳定
4. 放置 M1/M2 到两条最明显边带峰值，读取 f0/f1
5. 打开 OBW 99%，读取占用带宽
6. 把 Span 缩到 5 MHz 复查一次，确认读数稳定

记录模板（每次实验都填）：
- f0 = ___ Hz
- f1 = ___ Hz
- center_offset = ___ Hz
- deviation = ___ Hz
- OBW99 = ___ Hz
- sideband power (dBc) = ___ dBc

判定规则（用于与 PER/BER 联合解释）：
- 若 center_offset/deviation 更接近目标值，且 OBW 与理论关系一致，同时 sideband dBc 改善或波动减小，则可作为“链路改善有物理依据”的证据。
